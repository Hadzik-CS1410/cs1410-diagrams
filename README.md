# CS 1410 Diagrams & Steppers

Public, so Canvas pages can link and embed them. Students also get a copy of
each stepper inside the relevant assignment repo, but those repos are private
and only reachable while their dev container is running -- a Canvas page cannot
rely on either.

**This is a publish target, not a source.** The master copy of every file here
lives with its assignment in `cs1410-full-course`. Edit it there, then run:

    python scripts/publish_diagrams.py
